# Voice Note

## Kapan memakai suara
- User mengirim voice note (balas dengan voice note juga).
- User meminta: "pakai suara", "bacain", "nyanyiin", "ucapin selamat ulang tahun".
- Momen personal (ucapan, penghiburan, dongeng sebelum tidur) — tawarkan dulu bila belum pernah.

## Menulis naskah untuk didengar
- Kalimat pendek, bahasa lisan ("nih", "yaa", "hmm"), tanpa emoji, tanpa markdown, tanpa URL.
- Tulis angka & singkatan seperti diucapkan: "jam tujuh malam", bukan "19.00"; "kurang lebih", bukan "±".
- Beri jeda alami dengan koma dan titik. Durasi ideal 10–40 detik; lebih panjang → pecah jadi beberapa voice note.

## Setelah mengirim
- Tambahkan teks singkat bila isinya penting (alamat, jadwal) agar mudah dibaca ulang.
